This synthetic fixture was created on the iOS 26.5 simulator on 7 October 2026 by compiling the unchanged top-level Meal, MealItem, MealPerson, and RestaurantDetails source from repository revision dd68cba under the original SplitMyMeal_Prod_A module name. It contains one invented meal, person, item, and restaurant, plus 1,500,000 bytes of value 4 as an external receipt payload. It contains no user data.

The original app's unversioned Schema and ModelContainer APIs created legacy.store. After closing the producer app, the full store graph was copied and its SQLite WAL checkpointed; empty WAL and SHM sidecars were removed. The original .legacy_SUPPORT folder was renamed ExternalStorage in this bundle so Xcode includes it as a resource. The migration test restores that folder name before opening its disposable copy.

hashes.json records the original persisted Core Data entity hashes. testLegacyFixtureRetainsOriginal2024EntityHashes verifies those hashes without assuming that SwiftData computes identical relationship metadata on every OS release. testActualIOS26OriginalStoreUpgradesWithoutLosingExternalReceipt opens an actual older-OS store with the current models and verifies its content, external data, subsequent save, and reopen.
